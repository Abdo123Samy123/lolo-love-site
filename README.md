# رسالة إلى لولو

موقع رومانسي تفاعلي من صفحة واحدة، يبدأ بمشهد «بحبك» ويتحوّل إلى قلب، ثم رسالة شخصية وعجلة حظ برسائل باللهجة المصرية.

## التشغيل

افتح `index.html` في متصفح حديث. الصور من Unsplash وتحتاج اتصال إنترنت، ومصادر الصور موجودة في تذييل الموقع.

## التخصيص

- عدّل الرسالة داخل قسم «كلمتين من غير مقدمات».
- عدّل عبارات عجلة الحظ في مصفوفة `phrases` آخر ملف `index.html`.
- بدّل الصور بتغيير روابط `src` داخل معرض الصور.

التصميم متجاوب للموبايل والتابلت واللاب.
