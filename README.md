# لولو، حكاية بحبها

موقع حب تفاعلي بشكل مجلة ورسالة شخصية للولو. يبدأ بمشهد «بحبك» وكلمات بتتجمع في شكل قلب، ثم رسالة باللهجة المصرية، معرض صور، وعجلة حظ برسائل لطيفة.

## التشغيل

افتح `index.html` في متصفح حديث. يحتاج اتصالًا بالإنترنت لتحميل الصور والخطوط من Unsplash وGoogle Fonts. روابط الصور موجودة في تذييل الموقع.

## التخصيص

- غيّر نص الرسالة داخل قسم `letter`.
- عدّل رسائل عجلة الحظ في مصفوفة `phrases` بآخر الملف.
- استبدل روابط الصور في عناصر `img`.

التصميم متجاوب للموبايل والتابلت والكمبيوتر، ويحترم إعداد تقليل الحركة.
