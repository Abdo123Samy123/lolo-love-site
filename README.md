# مرصد لولو — كل نجمة حكاية

موقع حب تفاعلي على هيئة مرصد سماوي صغير. النجوم الثمانية تفتح كلمات ورسائل بالمصري، والصور تظهر ككواكب داخل كل رسالة. في قلب الخريطة زر للجواب الكامل، وشهاب يختار رسالة مفاجئة.

## التشغيل

افتح index.html في متصفح حديث. يحتاج اتصالًا بالإنترنت لتحميل صور Unsplash وخطوط Google Fonts. الموقع ثابت ومتوافق مع GitHub Pages.

## التفاعل

- اضغطي «ادخلي مرصدك» أو انتظري انتقال الافتتاحية.
- اختاري نجمة في السماء أو افتحي فهرس النجوم.
- اضغطي «خلّي شهاب يختارلك» لرسالة عشوائية، أو الكرة الوسطى لقراءة الرسالة كاملة.
- زر «الحركة الهادية» يقلل الحركة، كما يحترم الموقع إعداد تقليل الحركة في الجهاز.

## التخصيص

- نص الرسالة الكاملة موجود في المتغير fullLetter داخل index.html.
- الكلمات ورسائل النجوم والصور موجودة في المصفوفة stars.
- استبدلي روابط صور Unsplash داخل المصفوفة بصوركم الخاصة وقت ما تحبي.
